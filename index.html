Despliegue Gratis en Azure Static Web Apps

Sigue estos sencillos pasos para dejar esta app de quesos online y accesible desde tu celular gratis:

  1. Guarda este archivo: Descarga este código como index.html.
  2. Subir a GitHub: Crea un repositorio en GitHub llamado queso-control-app y sube el archivo index.html.
  3. Crear Azure Static Web App: Entra al Portal de Azure, busca Static Web Apps y haz clic en Crear.
  4. Conectar repositorio: Selecciona el plan Gratuito (Free), vincula tu GitHub y selecciona el repositorio de la app.
  5. Listo: Azure te dará un enlace https://...azurestaticapps.net para usar la app en tu teléfono o PC.
