¿Cómo funciona este modelo predictivo?

El sistema analiza la **velocidad diaria de venta (Kg/día)** de cada tipo de queso considerando los registros ingresados. Posteriormente, proyecta la demanda para los próximos 7 y 30 días y la contrasta contra las **existencias actuales en el Kardex** para sugerir la fecha óptima de compra a proveedores.

Desplegar QuesoControl AI en Azure (Free Tier)

Publica esta app gratis con GitHub & Azure Static Web Apps

Paso 1: Guardar este archivo e ir a GitHub

1. Descarga este archivo con el nombre index.html.

2. En tu cuenta de GitHub, crea un nuevo repositorio llamado queso-control-app.

3. Sube este archivo index.html al repositorio.

Paso 2: Conectar con Azure Static Web Apps

1. Ingresa al Portal de Azure.

2. Busca Static Web Apps y haz clic en + Crear.

3. Selecciona tu suscripción gratuita y el plan de precio Free ($0 / mes).

4. Conecta tu cuenta de GitHub y elige el repositorio queso-control-app.

5. En la sección Build Presets elige Custom y deja el App location en /.

Paso 3: ¡Dominio Web Listo para tu Teléfono!

Azure compilará tu aplicación en menos de 2 minutos y te otorgará una URL segura HTTPS. Podrás abrirla desde el navegador de tu celular para registrar ventas en el local o en bodega.
